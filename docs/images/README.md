# 首页预览

这些图片使用项目当前的 SwiftUI 视图离线渲染，并非实物照片或用户桌面截图。

| 文件 | 内容 |
| --- | --- |
| `layout-preview.png` | 网格布局编辑器与六种组件占位／数据预览 |
| `notifications-preview.png` | 通知岛运行中、等待确认、完成状态 |
| `connections-preview.png` | 内置插件目录和佳明账号连接入口 |

数值、设备名和通知文本都是固定示例，不读取真实 Codex／佳明账号，不监听键盘或音频，不连接开发板。背景由生成器绘制；没有使用私人壁纸、游戏海报或第三方桌宠角色图。

Mac 预览中的桌宠区域是占位；桌宠实际动画在小屏上执行。演示数据不代表性能测试、真实账户额度或健康记录。

## 重新生成

在已登录桌面的 macOS、Swift 6 环境中，从仓库根目录执行：

```sh
python3 tools/render-previews.py
```

脚本在忽略的 `build/docs-preview/` 内创建临时构建，复用固定的 Miucs 依赖，输出到本目录；首次构建可能需要下载依赖。生产源码和已安装应用不受影响。账号路径和偏好设置使用独立临时目录／域，生成后清理；临时源码仅替换了启动时加载私人壁纸的默认行为。

布局和配置页通过独立、屏幕外的 AppKit 托管窗口绘制原生控件，只读取该视图的绘制结果；不会截取用户桌面或其他窗口。通知状态与背景由 SwiftUI `ImageRenderer` 输出。

界面与示例数据入口：[PreviewMain.swift](../../tools/previews/PreviewMain.swift)。图片及原创背景按项目 MIT 许可证提供；系统字体与符号遵循其原有许可。
