# 开源准备：组件依赖与首次使用

本轮范围是通用配置与首次使用流程。这里记录实际边界，尚不代表可以直接发布开源版本。

| 组件 | 数据与运行依赖 | 本轮落地 | 后续缺口 |
| --- | --- | --- | --- |
| Miucs 桌宠 | 独立 MiucsCore、皮肤包、可选输入与音频权限 | 固定远程依赖；本地开发路径可覆盖；新用户按需授权 | 自定义皮肤安装与兼容性提示、资源授权复核 |
| Codex 用量 | 用户已登录的 Codex app-server、本机会话 | 自动发现／手选程序、统一数据目录、启用开关、状态检查 | 多账号识别、账号变更提示与版本兼容矩阵 |
| 通知岛 | 本地 JSON 事件、Codex Hooks | 应用内连接／修复／断开、固定命令路径、精确迁移与备份 | 更多 Agent 适配器；Hook 信任仍由用户在 Codex 完成 |
| 佳明健康 | garmin-mcp-cn 同款中国区认证与会话、Python 依赖 | 应用内账号／验证码交互、独立会话存储与更新、迁移旧会话、检查与退出 | 新凭据的中国区端到端登录仍待实际验证；需继续跟踪上游认证兼容性 |
| 蓝牙电量 | macOS 本机设备信息 | 无账号、无外部脚本依赖，向导说明缺失读数 | 更多配件的读取兼容性 |
| Mac 负载 | macOS/IOKit/SMC | 无账号、无外部脚本依赖，缺失值显示 — | CPU 温度目前仅识别 M4 系列，需扩展机型与传感器验证 |
| 图片／GIF | 用户导入的文件 | 文件复制到应用数据目录，无账号依赖 | 导出布局时的资源打包与缺失资源恢复 |

## 已建立的配置约定

- `ConnectionProfile` 是带版本号的本机配置，负责启用状态、程序位置和数据目录；不含密码、Token 或脚本正文。佳明仅支持中国区，不提供 Global 选项。
- 新安装先进入使用向导，外部账号源与桌宠输入默认不启用。老安装仅迁移一次，保留用户后续选择；损坏的配置不会被悄悄当作旧安装开启账号读取。
- 用量、健康组件共享禁用／待设置／检查中／已连接／部分可用／不可用状态。配置切换清理旧数据显示，旧异步结果不回填新配置。
- Codex 用量与通知使用同一个所选数据目录。安装通知命令会备份 `hooks.json`，不自动信任 Hook。
- Python 与第三方依赖随应用移动，不再保存构建机解释器的绝对路径。编译时仍需 uv 与字体来源。

## 下一阶段

项目原创代码已采用 [MIT License](../LICENSE)，README 已注明第三方内容的许可边界；构建后的 macOS 应用会包含该许可证。独立 Miucs 依赖、皮肤、壁纸及字体的授权复核仍需完成。

1. 应用内佳明账号／MFA 与会话管理已按 [BorisBW/garmin-mcp-cn](https://github.com/BorisBW/garmin-mcp-cn)（本机版本 `9cceb64`）实现。模拟服务覆盖登录、验证码、取消及退出；仍需用户在登录界面输入新凭据验证中国区服务的实际响应。Global 与官方 Personal API 不在范围内。
2. 内置组件已建立统一注册机制，名称、尺寸、添加入口和刷新／发送回调集中管理，见[架构说明](architecture.md)。后续再完善扩展约定；当前尚无通用插件 SDK。
3. 整理默认布局、固件兼容版本、首次刷机／升级／恢复流程，以及干净机器上的安装验证。
4. 复核壁纸、皮肤、字体及嵌入依赖的可再分发许可；补全发布签名、安装包与 CI。开发机的个人资源不得作为默认发布资源。

## 回归验证

`swift test` 使用隔离的偏好设置域与临时目录，覆盖首次启动、迁移、损坏配置、路径选择、禁用数据源与 Hook 状态。`python3 tests/test_connections.py` 覆盖 Hook 保留／迁移／移除、非法配置／符号链接／并发修改保护，以及佳明中国区会话校验、目录和时区传参。测试不读取真实凭据，也不修改真实 Codex 配置。

会话管理另有私有权限、迁入／退出不影响原文件、凭据不进入偏好设置、交互进程 MFA 与取消，以及退出后不可重新生成会话的回归测试。插件目录目前统一了内置插件配置入口；尚不是第三方插件加载框架。
